# MCH — Metal Chain

A Cardano token that tracks a basket of four metals (gold, copper, nickel,
magnesium), fed by live exchange prices.

**Status: planning.** No code yet. Start with [ROADMAP.md](./ROADMAP.md) — it
explains the four parts of the system, the three possible token designs, how the
index is calculated, what the data actually costs, and the open decisions.
